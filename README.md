# 🎥 Live Interview Monitoring View

## 📌 Project Overview

The **Live Interview Monitoring View** is a recruiter-facing dashboard developed as part of the **AI Interview Platform**. This module enables recruiters to monitor ongoing interviews in real time through a modern, responsive, and read-only interface. It provides complete visibility into interview activities, candidate information, AI-generated insights, and interview progress without allowing recruiters to modify interview data.

The dashboard is designed to improve the interview monitoring experience by presenting critical information in an organized, visually appealing, and user-friendly format. It serves as a centralized monitoring panel where recruiters can efficiently track multiple interview sessions while maintaining the integrity of the interview process.

---

# 🎯 Objectives

* Develop a professional recruiter monitoring dashboard.
* Display live interview information in a read-only format.
* Present candidate details in an organized manner.
* Visualize interview progress using interactive UI components.
* Display interview status indicators such as camera, microphone, internet connectivity, and screen sharing.
* Create a responsive interface that works across desktop, tablet, and mobile devices.
* Deliver an enterprise-level user experience with modern UI/UX design.

# ⚙️ How It Works

1. Open the dashboard in a web browser.
2. View all ongoing interviews from the recruiter dashboard.
3. Select a candidate from the interview list.
4. View complete candidate details.
5. Monitor interview progress.
6. Observe interview status indicators.
7. Review the live interview timeline.
8. Track AI-generated monitoring information.
